# Elf — маркетинговый HTML-прототип

Frontend-версия по доступным экранам https://app.foxy.ai/, просмотренным 5 октября 2026 года.

Основной вход: локальная регистрация → анкета интересов → себя / AI-персонажа → paywall. Преленд `/of-creators` пока не добавлен: его отрисованная версия недоступна для точной сверки. Прямой вход в каталог: `?entry=explore` или `#explore`.

Внутри: 12 шаблонов, 17 карточек AI-персонажей, локальные видео, подбор по категориям, поиск, фильтры, выбор персонажа, галерея, выбор плана, промокод, FAQ и возвраты. Фотография выбирается локально и не отправляется в сеть. Кнопка checkout открывает сообщение о демонстрации, не платежную форму.

## Запуск

```sh
npm ci
npm run dev -- --port 4173
```

Для обычного статического хостинга достаточно `index.html`, `app.js`, `auth.js`, `style.css`, `catalog.json`, `assets-extra.json` и папки `assets`. Открывать через HTTP, а не `file://`.

```sh
npm run build
npm run preview -- --port 4174
```

Сборка `dist` самодостаточна; все медиа и JSON копируются в нее. GitHub Pages публикует HTML из корня ветки `codex/elf-marketing-test`; сборка для него не обязательна.

## Измерения теста

События: `screen_view`, `topic_select`, `identity_select`, `template_select`, `character_select`, `category_select`, `plan_select`, `checkout_intent`, `promo_intent`, `photo_selected`, `search`. UTM сохраняются в событиях.

Сейчас события сохраняются **только в браузере посетителя** (`localStorage['elf.events']`). Общего отчета по трафику пока нет. Для подключения согласованной аналитики можно подписаться на `elf:analytics` или определить `window.ELF_ANALYTICS(event)` перед загрузкой приложения. Файлы фотографий, имя файла, пароли и платежные данные не входят в события.

## Границы

- Серверная авторизация, AI-генерация, подписки и серверная галерея не реализованы: текущий объем ограничен frontend до paywall.
- Разделы Create / Characters / Gallery до завершения создания персонажа показывают блокирующее сообщение, как в доступной сессии Foxy.
- Это выборка каталога, а не выгрузка всех 500+ персонажей. Остальные платные / закрытые экраны не проверялись.
- Категории и порядок «Popular» локальные демонстрационные; не воспроизводят серверную выдачу Foxy. Группировка внешности в магазине ориентировочная для примеров.
- Ветка фото упрощена: локальный выбор одной фотографии → тестовый paywall. На Foxy проверен первый экран загрузки; дальнейшие этапы без отправки фото не проверялись.
- Название, аватар, описания и FAQ адаптированы для Elf. Убраны чужие отзывы, счетчики генераций, заявления о 100k клиентов, искусственном дефиците и пожизненном владении. Цены $9/месяц и $72/год — тестовый вариант из просмотренного paywall, не реальные коммерческие условия запущенного продукта.

## Медиа

Временные публично отображаемые креативы получены с Foxy по просьбе пользователя для дальнейшей переработки. Права на эти материалы данным репозиторием не предоставляются. SVG управления и иллюстрации сохранены с просмотренных экранов; дополнительные иконки — Lucide (ISC). Шрифт Rethink Sans из страницы источника. В проект не включены cookies, токены, фото аккаунта, персональные данные или скрипты аналитики Foxy.

Результаты проверки регистрации: `design-qa-auth.md`. Общий статус с блокером преленда: `design-qa.md`. Локальные исходные скриншоты лежат в `evidence/` и исключены из публикации.

## Локальная регистрация и удержание

Гостевой пользователь сначала видит `#signup`; `#login` — повторный вход. Визуальный порядок Foxy сохранен: desktop — соцкнопки над email, mobile — email над соцкнопками. При вводе email раскрываются пароль и Continue. Минимум 8 символов — локальное правило прототипа, серверные ограничения Foxy не проверены.

В localStorage сохраняются профиль (`elf.account`), сессия (`elf.session`), настройки/анкета (`elf.preferences`) и текущий экран (`elf.lastRoute`). Пароль открытым текстом не сохраняется: используется PBKDF2-SHA256, случайная соль и 120000 итераций. Вход и прогресс восстанавливаются после перезагрузки и открытия корневой страницы. Logout удаляет сессию, сохраняя профиль. Один профиль на браузер; данные между устройствами не синхронизируются.

Это демонстрационная авторизация на устройстве, без серверной защиты доступа. Google / Facebook / Apple / X показывают пояснение и предлагают email; настоящего OAuth нет. Восстановление пароля по email также отсутствует. Локальный профиль не создает аккаунт на Foxy. Email и пароль не передаются в аналитику или сеть.

`npm test` проверяет создание профиля, отсутствие пароля в сохраненных данных, восстановление сессии, logout, отказ с неверным паролем, вход с правильным, несовпадающий идентификатор сессии и недоступное хранилище.
