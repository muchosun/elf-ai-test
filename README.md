# Elf — маркетинговый HTML-прототип

Frontend-версия по доступным экранам https://app.foxy.ai/, просмотренным 5 октября 2026 года.

Основной гостевой вход: преленд `of-creators.html` → локальная регистрация → анкета интересов → себя / AI-персонажа → paywall. Корневая страница отправляет нового гостя на преленд, а вошедшего пользователя возвращает на сохраненный экран. Прямой вход в каталог: `?entry=explore` или `#explore`.

Внутри: 12 шаблонов, 17 карточек AI-персонажей, локальные видео, подбор по категориям, поиск, фильтры, выбор персонажа, галерея, выбор плана, промокод, FAQ и возвраты. Фотография выбирается локально и не отправляется в сеть. Кнопка checkout показывает тестовую карту и переводит через отдельную Vercel Function на sandbox-форму MAVS. Реальные реквизиты вводить не нужно.

## Запуск

```sh
npm ci
npm run dev -- --port 4173
```

Для обычного статического хостинга нужны `index.html`, `app.js`, `auth.js`, `style.css`, `catalog.json`, `assets-extra.json`, `of-creators.html`, `preland.js`, `preland.css`, `preland-local.css` и папка `assets`. Открывать через HTTP, а не `file://`.

```sh
npm run build
npm run preview -- --port 4174
```

Сборка `dist` самодостаточна; все медиа и JSON копируются в нее. GitHub Pages публикует HTML из корня ветки `codex/elf-marketing-test`; сборка для него не обязательна.

## Измерения теста

События: `preland_view`, `preland_cta`, `preland_period`, `preland_faq`, `screen_view`, `topic_select`, `identity_select`, `template_select`, `character_select`, `category_select`, `plan_select`, `checkout_intent`, `checkout_redirect`, `checkout_error`, `promo_intent`, `photo_selected`, `search`. UTM сохраняются в событиях и в URL перехода с преленда на регистрацию.

Сейчас события сохраняются **только в браузере посетителя** (`localStorage['elf.events']`). Общего отчета по трафику пока нет. Для подключения согласованной аналитики можно подписаться на `elf:analytics` или определить `window.ELF_ANALYTICS(event)` перед загрузкой приложения. Файлы фотографий, имя файла, пароли и платежные данные не входят в события.

## Границы

- Серверная авторизация, AI-генерация, подписки и серверная галерея не реализованы: текущий объем ограничен frontend до paywall.
- Разделы Create / Characters / Gallery до завершения создания персонажа показывают блокирующее сообщение, как в доступной сессии Foxy.
- Это выборка каталога, а не выгрузка всех 500+ персонажей. Остальные платные / закрытые экраны не проверялись.
- Категории и порядок «Popular» локальные демонстрационные; не воспроизводят серверную выдачу Foxy. Группировка внешности в магазине ориентировочная для примеров.
- Ветка фото упрощена: локальный выбор одной фотографии → тестовый paywall. На Foxy проверен первый экран загрузки; дальнейшие этапы без отправки фото не проверялись.
- Название, аватар, описания и FAQ адаптированы для Elf. Убраны чужие отзывы, счетчики генераций, заявления о 100k клиентов, искусственном дефиците и пожизненном владении. Цены $9/месяц и $72/год — тестовый вариант из просмотренного paywall, не реальные коммерческие условия запущенного продукта.

## Медиа

Временные публично отображаемые креативы получены с Foxy по просьбе пользователя для дальнейшей переработки. Права на эти материалы данным репозиторием не предоставляются. SVG управления и иллюстрации сохранены с просмотренных экранов; дополнительные иконки — Lucide (ISC). Шрифт Rethink Sans из страницы источника. В проект не включены cookies, токены, фото аккаунта, персональные данные или скрипты аналитики Foxy.

Результаты проверки регистрации: `design-qa-auth.md`. Проверка нового преленда и входа в воронку: `design-qa.md`. Локальные исходные скриншоты лежат в `evidence/` и исключены из публикации.

## Локальная регистрация и удержание

Гостевой пользователь сначала видит преленд, затем `#signup`; `#login` — повторный вход. Из регистрации Back возвращает на преленд. Визуальный порядок Foxy сохранен: desktop — соцкнопки над email, mobile — email над соцкнопками. При вводе email раскрываются пароль и Continue. Минимум 8 символов — локальное правило прототипа, серверные ограничения Foxy не проверены.

В localStorage сохраняются профиль (`elf.account`), сессия (`elf.session`), настройки/анкета (`elf.preferences`) и текущий экран (`elf.lastRoute`). Пароль открытым текстом не сохраняется: используется PBKDF2-SHA256, случайная соль и 120000 итераций. Вход и прогресс восстанавливаются после перезагрузки и открытия корневой страницы. Logout удаляет сессию, сохраняя профиль. Один профиль на браузер; данные между устройствами не синхронизируются.

Это демонстрационная авторизация на устройстве, без серверной защиты доступа. Google / Facebook / Apple / X показывают пояснение и предлагают email; настоящего OAuth нет. Восстановление пароля по email также отсутствует. Локальный профиль не создает аккаунт на Foxy. Email и пароль не передаются в аналитику или сеть.

`npm test` проверяет создание профиля, отсутствие пароля в сохраненных данных, восстановление сессии, logout, отказ с неверным паролем, вход с правильным, несовпадающий идентификатор сессии и недоступное хранилище.

В меню есть Delete local account с отдельным подтверждением: удаляет профиль и локальные данные этого прототипа.

## Преленд

Реальные DOM, CSS, desktop/mobile экраны и медиа `https://foxy.ai/of-creators` получены 6 октября 2026 после восстановления доступа. Весь визуальный контент размещен локально; скрипты Framer, рекламного попапа, трекинга и аналитики Foxy удалены. Hero использует исходный видеокреатив, кнопки ведут в Elf. Нижний ролик с кофе уменьшен с 4K/60fps до 720px/30fps для небольшого слота страницы; исходник сохранен в локальной evidence.

Содержимое адаптировано к прототипу: собственный бренд, подписи к примерным медиа вместо чужих отзывов и счетчиков, FAQ про локальную демонстрацию, одна тестовая цена, согласованная с paywall ($9/месяц или $72/год). Поэтому это не буквальная копия всех текстов и коммерческих обещаний Foxy.

Для рекламы можно использовать прямой `of-creators.html`: он открывает преленд даже для уже вошедшего пользователя. Переключение месячного/годового варианта передается в сохраненные настройки paywall.

Из ранее замеченных несоответствий остается креатив Upload face photo: цветная иллюстрация пока не заменена исходным контуром лица. Это не входит в проверку преленда.

Отдельный checkout API: https://elf-mavs-checkout.vercel.app/api/health. Код и границы интеграции: `services/mavs-checkout/README.md`. Создание счёта и hosted форма проверены без отправки оплаты. Подписанный webhook и централизованный учёт завершённых оплат ещё не подключены.
